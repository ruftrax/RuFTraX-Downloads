## Installation

1. Download the ZIP for the application.
2. Open the downloaded package.
3. Read `READ_ME_FIRST` when included.
4. Double-click the included installer or build-and-install `.command` file.

These are macOS release packages. Individual packages may require JUCE or Apple development tools as described in their included instructions.

## Verification

SHA-256 checksums are published in [`SHA256SUMS.txt`](SHA256SUMS.txt).
