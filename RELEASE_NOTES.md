This release collects the seven approved RuFTraX macOS application packages in one public download location.

- RuFTraX Digital Vault v0.1.1
- RuFTraX TIMEFORGE v0.3.6

## Install

Download the ZIP for the application you want. Open it, read the included instructions, and double-click its installer or build-and-install `.command` file.

All packages are for macOS. Some packages build locally and therefore require the dependencies named in their included instructions.

SHA-256 checksums are available in `SHA256SUMS.txt`.
