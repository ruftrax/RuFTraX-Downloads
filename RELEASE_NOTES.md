## Install

Download the ZIP for the application you want, read its included instructions,
and double-click its installer or build-and-install `.command` file.

All packages are for macOS. Some packages build locally and therefore require
the dependencies named in their included instructions.

SHA-256 checksums are available in `SHA256SUMS.txt`.
