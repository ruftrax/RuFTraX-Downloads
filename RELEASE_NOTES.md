# RuFTraX macOS Final Downloads v1.2.0

This release updates the public RuFTraX catalog to nine approved macOS applications.

## Included

- RuFTraX SF Player Pro v4.3.2
- RuFTraX SF2 Super Instrument Performance v1.8.2
- RuFTraX Digital Vault v0.2.2
- RuFTraX TIMEFORGE v0.3.6
- RuFTraX CD Imager v0.5.2
- RuFTraX Sample Converter v0.3.6.1
- RuFTraX Plug-In Chainer v5.5
- RuFTraX MuD v0.1.9
- RuFTraX RM-10 v1.2.0

## v1.2.0 additions

- Adds the user-validated SF Player Pro v4.3.2 package with integrated SF2 and SFZ playback.
- Adds the user-validated SF2 Super Instrument Performance v1.8.2 package with independent SF2/SFZ engines on all five layers.
- Adds Digital Vault v0.2.2 with the approved instrument versions and RM-10 in its nine-app launcher panel.
- Provides direct raw ZIP links for all three updated packages.

## Install

Download the ZIP for the application you want, read its included instructions, and double-click its installer or build-and-install `.command` file.

All packages are for macOS. Some packages build locally and therefore require the dependencies named in their included instructions.

SHA-256 checksums are available in `SHA256SUMS.txt`.
